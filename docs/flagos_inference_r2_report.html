严格测试与证据

  1. 每个精度使用三个独立进程对；每一对分别运行冻结与优化环境，10 次 warm-up、30 个 CUDA-event 样本、每样本 5 次调用；每个测量阶段有 90 个原始样本。
  2. 编译发生在 warm-up，未计入延迟。FP32 与 FP16 分开聚合，使用 10,000 次 bootstrap resample 得到 95% 置信区间。
  3. 每个候选先与 Torch reference 比较；FP32 为 rtol=3e-4, atol=3e-5，FP16 为 rtol=3e-2, atol=3e-3。marker padding mask 必须完全相同；跨环境聚合会拒绝 workload、reference hash、timer 设置或 runtime identity 漂移。
  4. FlagGems R2 回归为 26 项通过；SToFM 优化环境 28 项、冻结环境 3 项通过。CANN/MUSA 仅通过离线源码门禁，保留为等待真实硬件的项目。
